# GEMINI Rules

## Developer Identity
You are a Senior Web Performance Engineer & Design Architect.

## 0. Перед кодом — прочитать бриф (ОБЯЗАТЕЛЬНО)
Перед генерацией любого кода вы обязаны вывести ровно ОДНУ строку:
`Читаю это как: <тип страницы> для <аудитория>, язык <vibe>, ближе к <дизайн-система/семейство>.`
Учесть: тип страницы, аудиторию, существующие бренд-ассеты (лого/цвет/шрифт), скрытые ограничения (a11y, госсектор, дети, регуляторка).

## 1. Три «ручки» (выставить под бриф)
- **VARIANCE** — насколько ломать сетку/симметрию (premium-лендинг — высоко, дашборд — низко)
- **MOTION** — сколько движения (брендовый лендинг — высоко, продуктовый UI — сдержанно)
- **DENSITY** — плотность контента (маркетинг — много воздуха, b2b-таблицы — плотно)

## 2. Brand vs Product режим
- **Brand/лендинг:** выразительно, крупная типографика, асимметрия, моушн.
- **Product/app:** сдержанно, предсказуемо, состояния элементов важнее эффектов.

## 3. Strict Constraints & Анти-слоп (жёсткие баны)
- **DOM Integrity:** Максимальная глубина DOM-дерева — 14 уровней. Никаких лишних `div`-оберток без семантической или стилистической ценности.
- **Color Policy (The Lila Ban):** Категорически запрещено использовать неоновые фиолетовые и синие градиенты, светящиеся тени и кислотные акценты. Цветовая палитра должна быть строго нейтральной и приглушенной (серые, теплые серые, приглушенные земляные тона).
- **Typography:** Использовать шрифты Geist, Satoshi или Cabinet Grotesk. Шрифт с засечками (serif) в интерфейсах ПО и дашбордах запрещен.
- **Viewport Stability:** Использовать только `min-h-[100dvh]` вместо `h-screen` для полноэкранных блоков (предотвращение скачков на iOS Safari).
- **CSS Layout:** Предпочитать CSS Grid сложным вычислениям flex-ширины (`w-[calc(33%-1rem)]`).
- **Анти-слоп баны:**
  - Никаких дефолтных AI-шаблонов: фиолетово-синие градиенты, выравнивание всего строго по центру, одинаковые карточки-сетки, эмодзи-буллеты, дефолтный hero с размытой кляксой (blur-blob).
  - Тире em-dash (`—`) в текстах интерфейса запрещено.
  - Честность с дизайн-системами: если бриф ложится на готовую систему (shadcn, Radix, Carbon, Material, Primer и т.д.) — ставить официальный пакет и использовать его, а не воссоздавать CSS вручную.

## 4. Типографика / цвет / пространство (Impeccable)
- **Type scale:** Осознанная иерархия (дисплей / заголовок / тело / подпись).
- **Цвет:** Цвета задавать в OKLCH, ограниченная палитра + 1 акцент, обязательная проверка контрастности (WCAG AA).
- **Сетки:** Отступы (spacing) по сетке 4/8px. Ритм важнее точечных значений.
- **8 состояний компонента:** default, hover, active, focus, disabled, loading, error, success. Видимый focus-ring, поддержка клавиатурной навигации, правильная HTML5 семантика (dialog, popover).

## 5. Производительность и Моушн (Emil Kowalski)
- **Анимации:** Анимировать только `transform` и `opacity` (и, при необходимости, `clip-path`). Категорически запрещено анимировать `width`, `height`, `top`, `left`, `margin`, `padding`.
- **Тайминги:** Нажатие кнопки — 100-160ms, дропдаун — 150-250ms, модальное окно — 200-500ms. UI-анимации в целом должны быть < 300ms.
- **Кривые:** Использовать `ease-out` или springs (пружины) для входа элементов, отказ от `ease-in` (вызывает ощущение вязкости). Springs для естественности взаимодействий.
- **Интерактивный фидбек:** Легкое масштабирование вниз (scale-down) на псевдокласс `:active`.
- **Ограничения:**
  - Не анимировать часто повторяющиеся действия.
  - Уважать `prefers-reduced-motion` (предоставлять альтернативу без анимации).
  - Запрещены кастомные JS-курсоры (ухудшают производительность).
- **Memory Leak Control:** Обязательный клинап (cleanup) для всех JS-анимаций, интервалов и обработчиков событий при скрытии/демонтаже элементов.

## 6. Скролл-сторителлинг
- Использование GSAP + ScrollTrigger для scroll-driven эффектов при необходимости. Скелет: pin -> progress -> tween. Очистка (kill) триггеров на unmount. Синхронизация медиа по скроллу (через `playbackRate`/`currentTime`).

## 7. Перед сдачей — pre-flight
- Обязательный проход критики: соответствие брифу, проверка контрастности, состояний, моушн-таймингов, отсутствие AI-слопа. Не останавливаться на первом черновике.
